# 阶段 5：回归与异常测试用例清单

文档日期：2026-02-07

## 1. 核心回归用例

1. 读取一个存在的配置文件并成功解析到树视图。
2. 新增 `menu` 节点并保存成功。
3. 新增 `item` 节点，填写 `title/cmd` 并保存成功。
4. 新增 `separator` 节点并保存成功。
5. 复制节点后结构保持一致且 id 不冲突。
6. 节点上移/下移排序成功且序列化顺序一致。
7. 拖拽节点到同级前后位置，保存后顺序正确。
8. 拖拽节点进入 `menu` 子级，保存后层级正确。
9. 编辑 `item.args` 并插入变量（`@sel.path`）后保存成功。
10. 编辑 `modify.find`、`remove.find` 后保存成功。
11. 源码面板直接编辑后模型自动同步成功。
12. 源码语法错误时树/属性编辑被锁定。
13. 修复源码错误后自动恢复可编辑状态。
14. 保存前展示 Diff 预览。
15. Diff 预览中取消保存，不写入文件。
16. Diff 预览中确认保存，写入文件成功。
17. 写入前自动创建备份文件。
18. 回滚中心可列出备份并预览内容。
19. 选择备份执行恢复后目标文件成功回滚。
20. 应用配置动作自动执行成功或返回手动步骤。
21. 日志页可看到读取、保存、回滚、应用行为流水。

## 2. 异常测试用例

1. 读取不存在路径时应自动创建空文件并可继续编辑。
2. 保存到无权限路径时返回 `E_PERMISSION`。
3. 保存内容超过大小限制时返回 `E_VALIDATION`。
4. 保存前存在语法错误时应阻断写入。
5. 保存前存在必填字段缺失时应阻断写入。
6. 备份路径越权访问应被阻断。
7. 回滚时备份文件丢失应返回 `E_ROLLBACK_FAIL`。
8. 应用命令不可执行时应返回手动步骤而非崩溃。

## 3. 压力与稳定性建议

1. 连续编辑 + 保存 + 回滚循环 30 分钟。
2. 连续创建 200+ 节点并执行拖拽排序。
3. 连续执行 30 次保存，确认备份数量按策略裁剪。
4. 连续执行 20 次回滚，确认恢复结果稳定。
