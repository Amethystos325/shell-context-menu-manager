# 阶段 0 产出：页面流程图（低保真）

文档日期：2026-02-07

## 1. 页面结构（低保真）

1. 配置页（Configuration）
   - 输入配置文件路径。
   - 按钮：读取配置、保存路径、打开备份目录。
2. 编辑页（Editor）
   - 左：菜单树（节点增删改排）。
   - 中：属性面板（按节点类型动态表单）。
   - 右：源码预览（查看/刷新）。
3. 发布页（Release）
   - 校验结果。
   - Diff 预览与确认。
   - 发布执行与结果反馈。
4. 回滚中心（Rollback）
   - 备份列表、版本预览、恢复按钮。
5. 日志页（Logs）
   - 操作流水、级别筛选、错误详情。

## 2. 主流程

```text
打开应用
  -> 配置页设置路径
  -> 读取配置
  -> 进入编辑页修改
  -> 触发校验
  -> 发布页查看 Diff
  -> 确认保存（自动备份）
  -> 应用配置（自动/手动指引）
  -> 日志页查看结果
  -> 如异常则进入回滚中心恢复
```

## 3. 错误场景流程

1. 语法错误：
   - 触发保存 -> 校验失败 -> 阻断保存 -> 定位到节点/行 -> 修复后重试。
2. 路径无权限：
   - 触发写入 -> 返回 `E_PERMISSION` -> 给出可执行指引（管理员权限/更换目录）。
3. 写入失败：
   - 触发写入 -> 返回 `E_WRITE_FAIL` -> 保持当前编辑态不丢失 -> 支持重试。
4. 回滚失败：
   - 触发恢复 -> 返回 `E_ROLLBACK_FAIL` -> 展示失败原因与手动恢复建议。

## 4. 页面间跳转规则

1. 只有读取成功后，编辑页主区域可编辑。
2. 编辑态有脏数据时，离开编辑页需二次确认。
3. 发布页仅在校验通过后允许“确认保存”。
4. 回滚成功后自动刷新编辑页与日志页。
