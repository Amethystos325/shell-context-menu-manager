# 阶段 0 产出：MVP 功能冻结清单

文档日期：2026-02-07  
适用范围：Shell UI 管理器（Electron）MVP（仅覆盖 `docs/Develop_Plan.md` 中 MVP 范围）

## 1. 本期支持（冻结范围）

1. 配置文件路径设置、读取、保存。
2. 菜单树可视化编辑：
   - `menu / item / separator` 的新增、删除、排序、基础复制。
3. 系统菜单规则编辑：
   - `modify / remove` 基础字段编辑（`find`、可见性、位置、菜单归类）。
4. 常用属性编辑：
   - `title`、`cmd`、`args`、`type`、`mode`、`image`、`tip`。
5. 变量辅助输入：
   - `@sel.path`、`@sel.dir`、`@sel.file.name`、`@sel.file.title`、`@sel.file.ext`。
6. 保存前语法与字段校验，失败阻断保存。
7. 保存前 Diff 预览，支持确认/取消。
8. 自动备份与一键回滚（按时间戳保留最近 N 份）。
9. 应用配置动作：
   - 优先自动刷新；
   - 失败时提供明确手动操作指引。
10. 日志面板：
    - 记录读取、校验、保存、回滚、应用动作与结果。

## 2. 本期不支持（延后项）

1. 全语法覆盖（仅实现 MVP 子集，复杂表达式与高级语法延后）。
2. 多文件复杂工程管理（MVP 先支持主文件+基础 `import` 识别与保留）。
3. 多主题 UI、插件系统、云同步、多人协作。
4. 自动修复语法（仅提示问题，不自动改写用户配置）。
5. 跨平台打包（MVP 先交付 Windows）。

## 3. 字段级约束

1. `item` 节点最小必填：
   - `title`、`cmd`。
2. `menu` 节点最小必填：
   - `title`。
3. `separator`：
   - 无属性编辑面板，仅支持位置变更与删除。
4. `modify/remove`：
   - `find` 必填；
   - 其他扩展字段后续阶段迭代。

## 4. 页面与功能映射（冻结）

1. 配置页：
   - 路径设置、读取、保存入口。
2. 编辑页：
   - 菜单树、属性面板、源码预览、变量插入。
3. 发布页：
   - 校验结果、Diff、备份、发布、回滚。
4. 日志页：
   - 操作流水与错误定位。

## 5. 变更控制规则

1. 阶段 1-5 内，如新增字段/功能不影响主链路，记录为“候选需求”，不进入当前 MVP。
2. 如新增需求影响已冻结范围，需单独评审并更新本文件版本号与日期。
3. 所有冻结范围变更必须同步更新：
   - `docs/Develop_Plan.md`
   - `docs/Develop_Progress.md`
